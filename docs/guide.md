# 使用说明

这份说明写给想自己搭一间小屋玩的人：会装软件、会打开命令行就够了，不需要会写代码。
想让屋里的鲸鱼娘接上你自己的 AI，看 [接入你自己的 AI](connect-ai.md)。

## 一、装好跑起来

1. **装 Node.js**：到 <https://nodejs.org> 下载 LTS 版本，一路下一步装完。需要 18.17 或更高版本。
2. **下载这个项目**：在 GitHub 页面点 **Code → Download ZIP**，解压到一个好找的地方。会用 git 的话也可以 `git clone https://github.com/moASPILyu/feiyu_room.git`。
3. **打开命令行，进到项目文件夹**：
   - Windows：打开解压出来的 `feiyu_room-main` 文件夹（用 git clone 的话叫 `feiyu_room`），在地址栏里输入 `powershell`，然后按回车。
   - macOS：打开“终端”，输入 `cd `（cd 后面有个空格），把文件夹拖进终端窗口，然后按回车。
4. **启动**：输入下面这行，然后按回车。

   ```bash
   npm start
   ```

   看到“礼物小屋已启动”就说明成功了。第一次启动时，程序会随机生成一个**口令**，存在项目里的 `data/token.txt`。

5. **打开页面**：在浏览器里打开 `http://127.0.0.1:17800/#key=你的口令`。
   页面会记住口令，并把它从地址栏里去掉。以后直接打开 `http://127.0.0.1:17800/` 就行。

命令行窗口要一直开着，关掉窗口或者按 `Ctrl+C`，小屋就停了。下次再打开时，还是进到这个文件夹运行 `npm start`。口令和屋里的东西都不会丢。

想改端口、名字、睡觉时间这些设置，先把 `config.example.json` 复制一份，改名为 `config.json`，然后只改你需要的那几项，改完重启小屋才会生效。每一项的说明见 [README](../README.md#配置)。

## 二、页面怎么用

### 房间

- **最上面**：左边是她的名字，右边是她现在在干什么。
- **风格按钮**：可以在“暖阳原木 / 北欧清晨 / 赛博夜”之间切换。三种风格只是换装修，家具和摆好的东西位置都不变。你选的风格只存在你自己的浏览器里，别人打开看到的是他们自己选的风格（没选过就用默认风格）。
- **左上角的时钟**：房间光线会跟着时间变，傍晚偏暖，夜里变暗。赛博夜本来就是夜景，不会再调暗。想提前看夜里的样子，可以在网址后面加 `?t=22`，例如 `http://127.0.0.1:17800/?t=22`。
- **点她**：她会挥挥手打个招呼。睡着的时候点她，她只会迷迷糊糊地回一句。
- **点屋里的东西**：打开这件礼物的详情。
- **一跳一跳的礼物盒**：表示有礼物还没摆好。盒子上的数字是有几件，点开可以看是哪些。
- **东西上的小红点**：这件东西你还没点开看过。

她自己会按时间活动：上午和下午坐在地毯上敲电脑或者站着发呆，中午和晚上捧着碗吃白米饭，刚收到礼物时抱着礼物，深夜在床上睡觉。如果你接了自己的 AI，AI 可以让她说话、换动作。

### 下面三个标签页

**她的东西**：送过的所有礼物，每件都写着摆在哪里。点一下打开详情。

**愿望单**：她想要的东西。
- 点“记一件她想要的”可以手动加一件，“为什么想要”和“链接”可以不填。
- 接了 AI 的话，她自己也会往愿望单里记东西，旁边会标着“她自己记的”。
- 每件后面都有“送给她”和“删掉”两个按钮，已经送过的会标“已经送了”。

**送点别的**：送愿望单以外的东西。
- 名字必须写，比如“一盆小多肉”。
- “是什么样的”可以不填。写上颜色和样子，图标会画得更准。
- 也可以选一张实物照片，图标会照着照片画。

### 送出去

不管从哪里送，最后都会弹出同一个确认框：

- **想说的话**：会写在礼物上，她能看到。可以不填。
- **怎么送**，三选一：
  - **送进小屋**：没有实物，只是送进屋里。
  - **真买了，还在路上**：等快递到了，在礼物详情里点“快递到了”。
  - **真买了，已经到了**：实物已经在你手上。

点了“送出去”以后：

1. 如果配了生图，小屋会给这件礼物画一个图标，一般要等几十秒到两分钟。没配生图的话，屋里会显示一个写着名字的礼物盒。
2. 如果接了你的 AI，小屋会通知它，由 AI 决定把礼物摆在哪、起什么名字、收到时说什么。
3. 如果 10 分钟内没人摆，小屋会自己找个合适的空位摆上：大件优先放地上，小件优先放架子上。

### 礼物详情

- **摆放位置**：从下拉框里选一个位置，就能把礼物挪过去：窗台、矮柜、搁板、书桌、地上……放满的位置不会出现在列表里。也可以选“收进箱子”，礼物就不在屋里显示了。
- **快递到了 / 到了，拍给她看**：只有“还在路上”的礼物才有这两个按钮。拍了照片的话，图标会照着实物重画。
- **看实物照片**：送礼或者快递到的时候传过照片才会有这个按钮。
- **换图标**：用你自己的图片当图标。白底图或者透明底图最好，白底会自动抠掉。
- **重画**：觉得图标画得不好就点一下，再画一次。
- 详情里还会显示：你送礼时说的话、她收到时的心里话、她想要它时说过的话、她拿它做过什么。

## 三、在手机上看

**手机和电脑连的是同一个 Wi-Fi：**

1. 在 `config.json` 里把 `"host"` 改成 `"0.0.0.0"`，然后重启小屋。
2. 查电脑的局域网 IP：
   - Windows：运行 `ipconfig`，找“IPv4 地址”，一般是 `192.168.x.x`。
   - macOS：打开“系统设置 → 网络”查看。
3. 第一次启动后，Windows 可能会弹出防火墙提示，勾选“专用网络”再点允许。
4. 在手机浏览器里打开 `http://电脑IP:17800/#key=你的口令`。打开后可以把页面“添加到主屏幕”，下次直接点图标进入。

**手机不在家里（用的是流量或者别的 Wi-Fi）：** 可以用 [Tailscale](https://tailscale.com) 这类组网工具。电脑和手机都装上，登录同一个账号，然后用电脑的 Tailscale IP 访问。

**不要**用路由器端口映射之类的办法，把小屋直接开放到公网。拿到口令的人能看到你送的所有东西，也能改。

## 四、让礼物自动画出来

小屋默认不画图标，屋里显示的是写着名字的礼物盒。想让它自动画，在 `config.json` 里配置 `image`，有两种方式：

- **用在线的生图接口**：任何 OpenAI 兼容的图片接口都可以，`provider` 写 `"openai"`，然后填 `baseUrl` 和 `model`。key 不要写进配置文件，要放在环境变量 `GIFT_ROOM_IMAGE_KEY` 里。设置方法：
  - Windows：先运行 `$env:GIFT_ROOM_IMAGE_KEY = "你的key"`，再在同一个窗口里运行 `npm start`。
  - macOS / Linux：运行 `GIFT_ROOM_IMAGE_KEY=你的key npm start`。
- **用你自己的程序画**：比如 ComfyUI 脚本或者本地模型。`provider` 写 `"command"`。

具体写法见 [README 的生图部分](../README.md#生图的三种方式) 和 [接口说明](API.md#生图)。

## 五、常见问题

**页面让我输入口令 / 口令忘了**
口令在项目的 `data/token.txt` 里，用记事本打开就能看到。如果你在 `config.json` 里写了 `token`，那就以 `config.json` 里写的为准。

**页面显示“连不上服务”**
小屋没在运行：检查命令行窗口是不是关了，重新运行 `npm start`。如果是在手机上看，还要检查第三部分的 `host` 和防火墙设置。

**启动时报错 `EADDRINUSE`**
端口 17800 被别的程序占用了。在 `config.json` 里把 `port` 改成别的数字，比如 17810。

**图标一直显示“正在画”**
生图一般要几十秒到两分钟。如果超过 5 分钟还没好，看一下运行小屋的命令行窗口，画失败的话那里会打印原因，常见的是 key 不对、余额不足、网络不通。修好以后，在礼物详情里点“重画”。

**礼物盒一直没被摆好**
正常情况下，10 分钟内会自动摆上，除非你在 `config.json` 里把 `autoPlaceMinutes` 设成了 `-1`。如果期间重启过小屋，下次启动时会把超时的礼物补摆上。也可以在详情里手动选一个位置。

**她白天也在睡觉 / 晚上不睡**
检查 `config.json` 里的 `utcOffset`（时区，北京时间是 `8`）和 `character.sleep`（睡觉时段，默认 `[23, 7]`，意思是 23 点到第二天 7 点）。

**想把屋子清空重来**
先停掉小屋，再把项目里的 `data` 文件夹改个名字，或者挪到别处当备份，然后重新启动。重新启动后会生成一个新口令。

**想换掉角色或者背景**
见 [README 的“换角色、加风格、改布局”](../README.md#换角色加风格改布局)。注意，自带的鲸鱼娘和房间背景不能商用。
